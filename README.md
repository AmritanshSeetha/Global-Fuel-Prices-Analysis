# Global Fuel Prices and Taxation Trends (2020–2026)

## Project Overview
This project analyzes global fuel prices, taxation policies, and subsidy trends across 84 countries and 7 regions from January 2020 to April 2026.

The aim is to understand how petrol, diesel, and LPG prices vary across countries and regions and how taxation, subsidies, and crude oil prices influence fuel costs.

## Dataset Information
- Total Records: 27,468
- Countries: 84
- Regions: 7
- Time Period: January 2020 – April 2026

## Tools and Technologies
- Tableau – Data visualization and dashboard creation
- Microsoft Excel / CSV – Dataset handling and preparation
- SQL – Data analysis and querying
- Python – Data cleaning and analysis

## Key Analysis Areas
- Petrol, diesel, and LPG price comparisons
- Regional fuel price trends
- Taxation and subsidy analysis
- Brent crude oil price trends
- Changes in fuel prices over time

## Project Objectives
1. Analyze global fuel price variations.
2. Compare fuel prices across countries and regions.
3. Study the relationship between taxation and fuel prices.
4. Understand the impact of subsidies on fuel costs.
5. Present insights through interactive Tableau visualizations.

## Project Status
Currently in development. Dataset preparation, analysis, visualizations, and dashboard development are being carried out.
